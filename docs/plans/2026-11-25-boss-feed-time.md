# 生活 Boss 投喂耗时实施计划

目标是在 `@dvi-lab/work-time` 按物品和品质估算持续投喂速度，并给出纯投喂和补料耗时。

规格见 `deep-vein-idle/docs/superpowers/specs/2026-11-25-boss-feed-calculator-design.md` 的第 4 节。实现沿用 ESM、最终角色属性和可信游戏文件。游戏声明只由 Node 构建入口提取，真实客户端文件留在调用方。测试服和正式服的生活 Boss 内部参数按用户确认视为一致。

- [x] 先更新 README 和设计契约。公开入口为 `createWorkTimeEngine(gameFile).estimateBossFeedRate({character, task: {bossId, itemId}})`。已知纯时间与综合时间分别返回。
- [x] 在现有有效引擎测试文件先写失败用例。覆盖分段成功率上限、农耕速度规则、参与和物品等级门槛、库存堆叠、未知路线和两个轮换站点的补料周期。
- [x] 实现纯投喂和稳定补料计算。读取游戏站点、路径及站位，按每条完整补料循环的件数平均。保留代表站位组，海妖生鱼、围城布匹有其他可核对站位组时报告范围。
- [x] 在现有预处理测试文件先写失败用例。确认语义化和显式投喂能力映射可以导出真实运行入口使用的声明，缺少其余能力时仍可编译普通配方。用正式服 1.0.4915 快照试编译和导入。
- [x] 用同源离线执行核对代表路线，至少覆盖五个首领及分段和堆叠样本。按 Chrome 测试服菜单的每时值除以同口径的每件值，记录综合效率标称及显示精度。
- [x] 执行现有四个顶层测试和隔离安装。回放冻结制造物流向量。记录离线执行、客户端标称和实际交付的覆盖边界。

实现和采样结果见[生活 Boss 投喂耗时验证](../boss-feed-verification.md)。
