# 工作耗时引擎设计

当前 `@dvi-lab/work-time@0.2.0` 主契约见[最终角色属性与游戏文件契约](final-character-contract.md)。角色最终属性、可信游戏文件、任务目标为输入，所有任务派生量由库计算。公共 API 与单位见根[README](../README.md)。

## 模块边界

- `src/index.js`：浏览器可打包主出口。
- `src/effective-engine.js`：最终等级／速度、风险、品质、升级、材料产物、目标次数和完整时间；不重建装备／精通／药水。
- `src/game-file.js`：独立 Node 构建入口，Acorn/eslint-scope 解析可信游戏文件并生成最小声明闭包 ESM；提取过程中收集每项能力的诊断，构建脚本输出警告；编译不执行输入，不自行联网。详见[预处理诊断](game-file-check.md)。生成模块的正常 import 会执行选中声明，非安全沙箱。
- `src/adapter.js`：只在实际使用分支检查必要能力，错误附功能／能力；版本和摘要不作准入条件。
- `src/batch-time.js`：共享 v3 路径／容量／相位。新入口注入最终 movement 解析；内部旧规则路径保留原移动计算，用于回归对照。
- `src/rule-engine.js`、`src/work-expectation.js`：内部0.1参考路径，不另增公开兼容入口。
- `src/domain.js`：冻结的采集技能／工具槽位。

运行入口不导入 Node 或解析器，不读取存档、网络、行情、页面或角色连接。消费工程负责可信文件加载与最终角色快照，构建时生成和打包游戏声明。包本身不带运行游戏资源。

## 行为与错误

输入快照不随任务推进。普通速度与升级速度分开；任务等级修正由模块结合游戏系数计算。材料每次尝试消耗；游戏先判烧毁，再判被抓，再生成主产物／bonus。缺省字段不静默补零／一。多分支升级要求明确输入物品，物品编码、升级结果及额外材料依赖游戏规则。

能力检查跟随实际分支。缺少可用品质不阻断纯时间；缺少升级规则不阻断普通配方；物流缺失保留已知工作时间。来源 SHA／版本仅追溯；能力存在仍不能证明未来游戏机制符合模型，新机制需要新样例。

物流固定主城仓库起终点、空包出发、每批存仓、最后回仓。只采集丢弃、偷窃及升级跳过物流；实例独立缓存路线。路径逐段取整，以有限周期处理大数量。不模拟未来升级、药水失效、工具免耗、宠物坐骑掉落、随机掉落对背包容量的反馈；不等同账号实测秒表。

## 历史资料与验证

`tests/fixtures/work-time-baseline/buddy/` 与 origin.json 为只读原证据。25文件保留 raw 和 UTF-8/LF 摘要，Git `-text` 保留原始字节。原完整 bundle 未复制，origin 中 Lab 路径仅为当时核验语境，不是运行或CI依赖。旧 runner/oracle/归档器只保存，不递归执行。

新旧接口分别回放全部14,950物流向量；新公共路径另验概率、品质、材料产物、升级与缺能力。隔离打包测试实际安装和调用两个公开入口，解析依赖从已安装 lockfile 包制成本地tarball预置，离线不需兄弟repo。npm test 显式列四个文件以兼容 Node20 Windows shell。历史数据不因新测试而重写。

npm 包白名单仅 src、README、LICENSE及自动包含的 package.json。MIT 适用于本包代码，不承诺扩展游戏资源权利。[本轮实际结果与限制](verification.md)。
