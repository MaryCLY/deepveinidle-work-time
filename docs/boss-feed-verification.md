# 生活 Boss 投喂耗时验证

采样日期为 2026-11-25。正式服规则来自 1.0.4915，测试服候选菜单来自 `index-BOwSec4u.js`。本次按已确认的前提使用一致的生活 Boss 内部参数。正式服源码指纹和编译方式见[游戏文件预处理](game-file-check.md#生活-boss-声明)。

## 正式服客户端离线回放

用无账号数据的合成人物，固定技能 110 级、速度倍率 1、移动值 1000 和 28 格背包。用客户端投喂分段的逐 Tick 成功率核对纯投喂时间。回放原客户端的完整工作、行走和补料状态，固定判定成功以单独核对物流。普通容量样本在首次进入工作后计量 96 次补料和 2,688 件交付。可堆叠样本取满同种物品后计量 100 件交付。

五个首领共 14 类代表路线均匹配，纯投喂和物流偏差均在浮点舍入内。包括熔炉之心罕见陨铁矿、稀有陨铁锭、煤，海妖生鱼和熟鱼，菌群原木、弓和法杖，枯萎之花作物、草药和药剂，以及围城布匹、皮甲和布甲。

逐项调用正式服声明中的 112 种候选物品和五个品质，共 560 个组合，均返回可计算状态。海妖普通虾的三个站位组各回放 120 次补料，综合耗时分别为 2.413176、2.434605 和 2.423890 秒/件，与模型输出范围一致。

历史熔炉之心配置下，罕见陨铁矿复算为 1.401818 秒/件，其中纯投喂 1.054943 秒和物流 0.346875 秒，与 2026-11-25《生活 Boss 投喂性价比计算页规格》第 8 节记录的约 1.40 秒/件对齐。《陨铁锭制造耗时复核（2026-11-25）》记录的锻造 104 级、速度倍率 5.274843、移动值 4080 和 32 格背包，对制备 4,322 个稀有陨铁锭仍得 6,919.8 秒，站点为熔炉 42。
